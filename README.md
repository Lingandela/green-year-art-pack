## What to mark up

1. Keep strict 16-color procedural, or allow a tiny indexed sheet for farmer + house?
2. Field plants: 2D silhouettes vs voxel projection?
3. Cottage roof vs stall (both rust).
4. Interior: wood box in soil void, or cutaway?
5. Locked plots are two posts — easy to miss.

Inspect close-up is the quality bar. Floppy budget is 1.44 MB (game is ~263 KB).
